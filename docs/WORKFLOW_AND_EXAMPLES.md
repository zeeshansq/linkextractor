# 🔄 Workflow Architecture & Working Examples

This document details the complete operational lifecycle of **DigiSkills Video Links Extractor** along with real-world output examples in JSON, CSV, and Excel formats.

---

## 🏗️ System Workflow Architecture

```mermaid
sequenceDiagram
    autonumber
    actor User
    participant WebUI as Web Dashboard (App.js)
    participant Server as FastAPI Server (main.py)
    participant Extractor as DigiSkills Engine (digiskills.py)
    participant Browser as Playwright Chromium (browser.py)
    participant LMS as DigiSkills LMS (lms.digiskills.pk)

    User->>WebUI: Click "Login Browser"
    WebUI->>Server: POST /api/login
    Server->>Browser: Launch Headful Browser Context
    Browser->>LMS: Navigate to https://lms.digiskills.pk
    User->>LMS: Enter Credentials / 2FA / CAPTCHA
    Browser->>Browser: Save Session (.auth/state.json)
    
    User->>WebUI: Click "Fetch Courses"
    WebUI->>Server: GET /api/courses
    Server->>Extractor: get_enrolled_courses()
    Extractor->>LMS: Scrape Dashboard Cards
    LMS-->>WebUI: Return Course List (Graphic Design, SEO, etc.)

    User->>WebUI: Select Course & Click "Start Extraction"
    WebUI->>Server: GET /api/stream-extraction (SSE Stream)
    
    loop For Each Lecture Topic
        Extractor->>Browser: Open Lecture Topic Page
        Browser->>LMS: Load DOM & Embedded YouTube iFrames
        Browser->>Extractor: Return YouTube Video Link & Video ID
        Extractor->>Server: Progress Event (SSE)
        Server-->>WebUI: Live Update Progress Bar & Table Row
    end

    User->>WebUI: Click "Export Data (Excel / CSV / JSON)"
    WebUI->>Server: GET /api/export/excel
    Server-->>User: Download File with Clickable YouTube Hyperlinks
```
