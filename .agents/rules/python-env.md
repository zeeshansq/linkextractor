# Python Environment Configuration

Always use the Python virtual environment located at:
- **Path**: `C:\venv\envTemp`
- **Interpreter**: `C:\venv\envTemp\Scripts\python.exe`
- **Activate Script**: `C:\venv\envTemp\Scripts\Activate.ps1` (PowerShell) or `C:\venv\envTemp\Scripts\activate.bat` (CMD)

When running Python commands, tests, servers, or scripts for this project, always execute using `C:\venv\envTemp\Scripts\python.exe` or with `C:\venv\envTemp` activated.
